# チーム組み合わせメーカー

ファミリーバドミントン練習会用の **チーム振り分け & 対戦表自動作成** アプリ（Next.js）。

## 機能

- 📒 **メンバー帳**：登録した名前を端末に保存（次回起動時もそのまま）
- ✅ **当日の参加者選択**：メンバー帳からチェックして参加者を絞り込み
- 🎲 **形式**：トリプルス（3人/既定）/ ダブルス（2人）
- 🏟 **コート指定**：1〜3コート（「倉庫側」「中央」「ステージ側」と表示）
- 👨‍⚖️ **審判担当チーム**：あり/なし（休みチームを審判 or 休憩として表示）
- 👆 **タッチ式リビール**：自分の名前をタップすると、自分のチームが大きくアニメ表示
- 🎯 **手動でチーム固定**：一部メンバーを特定チームに固定 → 残りはランダム配置
- 🧮 **端数 +1 人チーム**：人数が割り切れない場合、自動で +1 人チームを混ぜる
  （例：10人÷3人 → 4・3・3 の3チーム）
- 🏆 **総当たり戦**：コート数に応じて試合回を自動分割

## 使い方の流れ

1. **設定画面**
   - 形式（トリプルス / ダブルス）
   - コート数（1〜3）
   - 審判担当の有無
   - **メンバー帳**：名前を1名ずつ追加 / 1行1名でまとめて追加 / 編集・削除
   - **今日の参加者**：メンバー帳から今日参加する人をタップで選択
   - **チーム編成プレビュー**：人数と編成（端数があれば +1 人チームの表示）
   - （任意）**手動でチーム固定**：固定したい人だけ「チーム X」を選択（残りは自動）
   - 「ランダム配置 → タップ開始」ボタン
2. **タッチ式リビール画面**
   - 参加者名のグリッドが表示される
   - 各自スマホを受け取って **自分の名前をタップ** → チーム番号が大きくアニメ表示
   - 画面をタップすると次の人へ
   - 全員終わったらチーム一覧と「対戦表を作成」が出る
3. **対戦表画面**
   - チーム編成（メンバー名つき）
   - 試合回ごとに、コート別（倉庫側/中央/ステージ側）の対戦が表示される
   - チーム数が多くてコートに収まらない場合は自動で次の試合回に分割
   - 「再シャッフル」でチーム振り分けからやり直し

## セットアップ

### 必要なもの

- Node.js 18 以上

### 起動

```sh
cd team-maker
npm install
npm run dev -- -H 0.0.0.0
```

ブラウザで <http://localhost:3000> を開く。

スマホからは同じ Wi-Fi 内で：

```sh
# Mac のローカル IP を確認
ipconfig getifaddr en0
# → 例: 192.168.0.16

# スマホのブラウザで http://192.168.0.16:3000
```

※ 別IPからアクセスする場合は `next.config.mjs` の `allowedDevOrigins` に追加。

## デプロイ

### Vercel（推奨）

```sh
npm install -g vercel
vercel
```

質問に Enter で答えていけば公開URLが発行される。以降は `vercel --prod` で更新。

## 対戦表のロジック

総当たり戦（Circle Method）で全チーム対戦の組み合わせを生成。

- チーム数が **奇数** → 各回1チームが余り、審判（または休憩）担当
- チーム数が **偶数** → 全チームが毎回対戦（審判は不要）
- マッチ数がコート数より多い場合 → 同一回を複数試合に分割

## チームサイズの計算（端数 +1）

参加者数を `baseSize`（2 or 3）で割り、余りは先頭チームから 1 人ずつ配分。

| 参加者 | 形式 | チーム編成 |
|:--:|:--|:--|
| 9 | トリプルス | 3, 3, 3 |
| 10 | トリプルス | **4**, 3, 3 |
| 11 | トリプルス | **4**, **4**, 3 |
| 7 | トリプルス | **4**, 3 |
| 5 | ダブルス | **3**, 2 |
| 6 | ダブルス | 2, 2, 2 |

## データ保存

メンバー帳は **localStorage** に保存（`team-maker.members.v1` キー）。
ブラウザのデータを消すと初期化される点に注意。
